# Stage 5: direct-call targets not covered by .pdata

The prior function count needed careful correction. GNU objdump decoding of the original `.text` including its full virtual size **through RVA 0x1D0BA** yields 305 unique internal direct-CALL target RVAs. An earlier 304 count came from treating RVA 0x1D000 as an artificial code boundary and omitting target **0x1D050**. That missing target does not affect the outside-unwind set.

- **590**: unwind/exception ranges (not the number of original source functions).
- **305**: unique direct-call targets in the full executable .text virtual span.
- **67**: distinct direct-call targets outside every .pdata range.
- Among these 67: **11** PE import jump thunks, **2** immediate-return stub candidates, **1** local unconditional-jump stub, **53** unresolved leaf/helper candidates.
