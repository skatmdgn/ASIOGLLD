# 원본 버퍼 설정 양방향 함수 재구성 (STATIC)

SHA-256 `e2a9088a71e61362b4b1cf9d11717a1278ef26c940e7ca716290cab7a93c5cfd`; 원본 기준 RVA. 이 문서는 **기계어에서 유도한 제어 흐름 명세**로, 원 개발자의 C++ 원문도 Windows 런타임 검증도 아니다.

## RVA 0xB280: 버퍼 값 → UI 슬라이더 위치

- 작업 중인 설정 객체의 flags 비트 2(0x4)를 검사. 커스텀 모드면 +0x4에 보관한 정수 버퍼 값을 **[10,100]으로 클램프**하여 반환.
- 일반 모드에서는 **RVA 0x204B8의 DWORD 테이블 [10,50,100]**을 탐색한다.
- 값이 세 항목과 정확히 일치하면 인덱스 **0 / 1 / 2**를 반환한다.
- 정확한 항목과 다르면 인접 두 값의 정수 중앙값(30,75)과 비교해 가까운 인덱스를 선택한다. 경계값 30은 1, 75는 2.
- **마지막 원본 분기 0xB301은 EAX=0을 반환**하기 때문에 100을 초과하는 비정상 값도 0으로 돌아가는 코드를 확인했다. Phase 1에서는 일반적인 클램프 함수로 임의 교정하면 안 된다.

## RVA 0xB310: UI 슬라이더 위치 → 버퍼 값

- 커스텀 모드면 위치 정수 값을 **[10,100]으로 클램프**하여 반환.
- 일반 모드면 위치 **0,1,2**에 각각 **10,50,100**을 반환.
- 그 밖의 인덱스(음수 포함)는 **10**을 반환.

## 검증 범위

- 위 알고리즘의 원본 명령어와 데이터 테이블을 직접 확인.
- `tools/buffer_slider_model.py`: 원본 의미를 유지한 **분석용 Python 모델**; DLL 교체 코드 아님.
- `tests/test_buffer_slider_model.py`: 중앙값 29/30, 74/75와 사용자 정의 경계, 범위 밖 처리 등 **4개 테스트 통과**. 이 테스트는 작성한 정적 모델의 일관성을 확인하는 것이지, 실제 원본 DLL과 실행 결과를 비교한 것이 아님.
- GUI로 표시되는 단위, sample rate/WASAPI 실제 period와의 환산, 확인 버튼 뒤 적용 시점은 계속 복원해야 함. 속도 개선이나 최적화 없음.
