# 9차: 남은 59개 간접 호출 분류

8차 결과 164개 비-IAT 간접 호출 중 기존에 정적 ABI/객체 포인터 근거가 있는 위치는 **30+75=105개**. 9차에서 나머지 **59개 모두 원본 명령어와 대조**했다.

- 17개는 `CAsio`, `CClassFactory`, 설정 객체/포트 리스트, DLL 초기화 주변 코드에 있다. 원본 가상 메서드 슬롯에 따라 AddRef, QueryInterface, Release, C++ 소멸자, 팩토리 생성 콜백 등의 **정적 역할 후보**로 나눴다.
- 42개는 RVA `0xC345–0x1D06E`의 C/C++ 런타임·예외 처리·초기화 유사 코드에 분포한다. 예외 디스패치, DLL 초기화 후킹, 지연된 함수 포인터 호출 등이 보이지만, 모두 MSVC CRT라고 링크 맵으로 증명한 것은 **아니다**.
- **코드 영역 분류와 런타임 대상 함수 식별은 다르다.** 따라서 59개가 모두 완전히 규명됐거나 전체 역공학을 완료했다고 주장하지 않는다.

원본 59개 RVA와 정확한 명령어 바이트: `analysis/BATCH9_LAST59.csv`; 클래스 팩토리의 18개 핵심 원본 바이트: `analysis/BATCH9_FACTORY_PINS.csv`; 읽기 전용 검사: `tools/batch9_verify_original.py`. 전체 164개 호출의 정적 근거·추론·미확인 대상 목록, 더 강한 23개 팩토리 핀, 전체 Python 모델과 13개 신규 테스트는 **Batch9 ZIP**을 참조한다.

로컬 분석: 신규 13/13, 이전 Batch6 11/11 + Stage5 4/4 + Batch7 9/9 + Batch8 11/11 재실행 = 총 **48/48** 분석·모델 테스트 통과. **이는 실행 중인 원본 DLL/재현 DLL 비교 테스트가 아니다.** CI 실행 0회, 최적화 0건.
